# IPTV-List
Listas de IPTV creadas por mi con señales libres

*Canales recopilados por mi y verificado que funcionan 100%*

Para usar las listas seguir los siguientes pasos:

Seleccionar la lista que se quiere utilizar y dar click en "Raw"
<img width="1884" height="863" alt="image" src="https://github.com/user-attachments/assets/8c383a45-7e45-4d3d-97cb-8a2dc1cfa75e" />



Copiar la URL

<img width="1428" height="1015" alt="image" src="https://github.com/user-attachments/assets/136a5c00-69ed-42fe-a815-cb733769607c" />



Abrir un reproductor, para este ejemplo VLC y seleccionar la opcion "abrir ubicación de Red"

<img width="1194" height="823" alt="image" src="https://github.com/user-attachments/assets/3dde9490-3898-4cab-b662-2292eacf91cd" />



Pegar la ruta y click en "Reproducir"

<img width="1193" height="824" alt="image" src="https://github.com/user-attachments/assets/6dad367c-688c-4b2d-bcb1-50effa7b97e2" />

Se cargara la lista de canales disponibles, doble click en el que se quiera reproducir y disfrutar de las señales libres (ojo, libres, no de pago)
